### 1.2 关键数据发现与矛盾量化分析（为什么不能盲目巡航？）

通过对表 1-1 的数据进行深入微积分与运筹学分析，提炼出决定系统成败的**四大核心数据发现**：

#### 发现一：移动成本对检测成本的“数量级压制”（极重位移代价）
* 机器狗移动 $100\text{ m}$ 耗时 $20\text{ s}$，等价于**检测整整 4 个频道的耗时**；从原点移动到边缘 $1800\text{ m}$ 耗时 $360\text{ s}$，等同于进行 **72 次静态测向**！
* **决策推论**：机器狗的路径必须是高度精简的“狙击型”轨迹，绝对不能像扫地机器人一样进行全图密集栅格遍历覆盖。必须**在原点及少数骨干节点驻留，榨干当前位置的全部全频段信息后，再实施大步长机动**。

#### 发现二：原点 $(0,0)$ 全频扫描的几何覆盖率分析
* 区域半径 $R = 1800\text{ m}$，干扰源最小接收半径 $R_{\text{recv}}^{\min} = 1000\text{ m}$。
* 机器狗在原点 $(0,0)$ 发起 20 个频道的全量扫描（耗时 $20 \times 5 + 19 \times 1 = 119\text{ s}$，不足 2 分钟）：
  $$\text{原点直接可测覆盖面积比例} = \frac{\pi (1000)^2}{\pi (1800)^2} = \left(\frac{5}{9}\right)^2 \approx 30.86\%$$
  若干扰源有效半径达到上限 $1500\text{ m}$，则覆盖比例激增至 $\left(\frac{15}{18}\right)^2 \approx 69.44\%$！
* **数据发现结论**：**原点起手全频普查具有压倒性的信息收益比**。平均而言，在开局第 119 秒内，系统就能直接捕获 $40\% \sim 60\%$ 干扰源的第一条高信噪比示向线（SVD Line）！

#### 发现三：示向度误差 $\pm 1^\circ$ 的几何发散性
* 距离检测点 $r = 1000\text{ m}$ 处，$\pm 1^\circ$ 误差对应的圆弧横向线位移误差为：
  $$\Delta w = 2 \cdot r \cdot \sin(1^\circ) \approx 2 \cdot 1000 \cdot 0.01745 = 34.9\text{ m}$$
* **致命矛盾**：$34.9\text{ m}$ 大于清除半径 $R_{\text{clear}} = 20\text{ m}$！
* **结论**：仅靠单点测向绝不可能盲目冲刺清除；必须进行**双点测向几何交会**，或者在逼近过程中实施**动态闭环修正**。

### 1.3 理论物理下界定理（Theoretical Lower Bounds）

为评估后续所设计算法的优劣，基于最优松弛条件建立理论完工时间的刚性物理下界。

**定理 1.1（无碰撞无误差完美信息下的时间下界）**：  
设区域内存在 $N$ 个干扰源，位置完全已知为 $\mathbf{x}_1, \dots, \mathbf{x}_N$，机器狗从 $(0,0)$ 出发访问并清除全部目标的虚拟时间必满足：
$$T_{\text{virtual}} \ge \frac{L_{\text{TSP}}^*(\{\mathbf{0}\} \cup \{\mathbf{x}_1, \dots, \mathbf{x}_N\})}{v_{\text{dog}}} + 5.0 \times N$$
其中 $L_{\text{TSP}}^*$ 为欧氏旅行商问题最短回路/路径长度。

* **代入量化**：对于半径 $1800\text{ m}$ 圆内均匀分布的 14 个点，根据 Beardwood-Halton-Hammersley 定理，$L_{\text{TSP}}^* \approx 0.712 \sqrt{14 \cdot \pi \cdot 1800^2} \approx 8480\text{ m}$。
* 最优行进时间下界：$t_{\text{move}}^* \approx 8480 / 5 = 1696\text{ s}$。
* 理论极限总时间下界：$T_{\text{bound}} \approx 1696 + 14 \times 5 \approx 1766\text{ s}$。  
此下界为任何在线搜索算法无法逾越的物理红线，用于指导我们在后续设计中衡量搜索盲目性的溢出代价。

## 2. 问题一：两点测向误差多边形与圆覆盖反例严格证明

### 2.1 命题重述与几何建模
* **命题**：已知某全向干扰源在两个不同检测点处测得示向度，各存在 $[-1^\circ, 1^\circ]$ 误差。两束示向光束在平面内相交形成一个四边形或三角形的闭合“定位区域” $\Omega$。设该区域的几何直径（任意两点间最大距离）为 $D = \text{diam}(\Omega) = \sup_{\mathbf{p}, \mathbf{q} \in \Omega} \|\mathbf{p} - \mathbf{q}\|$。以 $D$ 为直径作圆，记为 $\mathcal{C}_D$。问：**该圆是否一定能完全覆盖此定位区域？**

### 2.2 严格数学反例证明（严谨代数与几何推导）

**结论**：**以定位区域直径为直径的圆，在一般情况下不能覆盖此定位区域！**

#### 代数反例构建（正三角形反例）：
设两个检测点 $S_1, S_2$ 的示向线误差边界在平面上截出的定位区域 $\Omega$ 为一个边长为 $a$ 的**等边三角形** $\triangle ABC$（如图 2-1 所示）：

```
                  A (顶点溢出圆外！)
                 / \
                /   \
               /     \
              /   O   \  <-- 区域直径圆以 BC 中点为圆心，半径仅为 a/2
             /         \
            B-----------C
               边长 a = D
```
*图 2-1：正三角形在直径为 $D$ 的圆下的边界溢出反例示意图*

1. **求定位区域直径 $D$**：
   对于正三角形 $\triangle ABC$，集合内任意两点的最大欧氏距离为其边长，即：
   $$D = \text{diam}(\triangle ABC) = \|\mathbf{x}_B - \mathbf{x}_C\| = a$$
2. **构建以直径为直径的圆 $\mathcal{C}_D$**：
   根据题设，该圆的直径为 $D = a$，故该圆的半径为：
   $$R_D = \frac{D}{2} = 0.5 a$$
3. **考察完全覆盖该三角形的最小圆半径**：
   根据凸几何学，能完全覆盖一个平面凸集的最小圆称为其**外接最小覆盖圆（Minimum Enclosing Circle）**。对于正三角形，其最小覆盖圆即为其外接圆，圆心为三角形几何质心，其外接圆半径由正弦定理给出：
   $$R_{\text{circum}} = \frac{a}{2 \sin(60^\circ)} = \frac{a}{\sqrt{3}} \approx 0.57735 a$$
4. **严格代数不等式比对**：
   由于：
   $$R_D = 0.5 a < 0.57735 a = R_{\text{circum}}$$
   半径不足！若圆心置于最长弦 $BC$ 的中点，圆恰好经过点 $B$ 和点 $C$，此时该圆圆心到第三个顶点 $A$ 的距离为三角形的高：
   $$h = \frac{\sqrt{3}}{2} a \approx 0.8660 a > R_D = 0.5 a$$
   顶点 $A$ 距离圆心的距离远大于圆的半径 $0.5a$，**顶点 $A$ 必定严重暴露在圆外部！**

#### 引申现代几何学定理支撑（Jung 定理）
在二维欧氏空间中，平面集合的最小覆盖圆半径 $R_{\min}$ 与集合直径 $D$ 满足著名的 **Jung 定理（Heinrich Jung, 1901）**：
$$R_{\min} \le \frac{D}{\sqrt{3}}$$
等号当且仅当集合为正三角形时成立。而以 $D$ 为直径的圆，其半径固定为 $R = \frac{D}{2}$。由于 $\frac{D}{2} < \frac{D}{\sqrt{3}}$，该圆的半径在所有非扁平图形（如正三角形、钝角三角形及多数四边形）中均无法容纳外接点。

**本问学术结论**：该命题不成立。只有当定位区域退化为特定细长型长方形（对角线为直径且钝角足够大）时才可能被覆盖。在实际测向交会四边形中，必须采用外接最小覆盖圆算法（如 Welzl 算法）构造覆盖圆，而非直接以最大距离为直径作圆。

## 3. 问题二：第二检测点的解析约束建模、多维量化评估与双准则最优选点

### 3.1 物理本质与破局推导：全域“一击必杀”为什么撞墙？

在第一检测点 $S_1(x_1, y_1)$ 测得示向度 $\theta_1$（误差 $\pm\varepsilon = \pm 1^\circ$）。直观设想是：能否选取一个第二检测点 $S_2$，使得对全纵深 $\rho \in [5\text{ m}, 1500\text{ m}]$ 的目标，交会嫌疑多边形都能落入车载光学清除圆（直径 $D_{\text{opt}} = 40\text{ m}$）内部，实现“单点停靠、一击必杀”？

**几何物理铁证否定了这一全域设想**：
第一站发射光束截宽满足 $w_1(\rho) = 2\rho\sin(1^\circ)$。当目标位于最远端 $\rho = 1500\text{ m}$ 时：
$$w_1(1500) = 2 \times 1500 \times \sin(1^\circ) \approx 52.36\text{ 米} > 40\text{ 米}$$
单根测向光束自身的粗细就已经超越了车载光学设备的捕获直径！因此在全域 $[5\text{ m}, 1500\text{ m}]$ 上，不存在任何能绝对保证单次一击必中的检测点（全域必中集合严格为空集）。

由此推导出关键临界距离阈值：
$$D(\rho) \approx \frac{2\rho\sin(1^\circ)}{\sin\gamma} \le 40\text{ m} \implies \rho \le \frac{20\sin\gamma}{\sin(1^\circ)}$$
- **正交极限（$\gamma = 90^\circ$）**：$\rho_{\text{crit}}(90^\circ) = \frac{20}{\sin(1^\circ)} \approx \mathbf{1146\text{ 米}}$；
- **倾斜安全底线（$\gamma = 30^\circ$）**：$\rho_{\text{crit}}(30^\circ) = \frac{10}{\sin(1^\circ)} \approx \mathbf{573\text{ 米}}$。

**破局战术结论**：在 $\rho \le 573\text{ m}$ 时，实施 **Case A（单点驻停 5 秒一击必杀）**；在 $\rho > 573\text{ m}$ 时，实施 **Case B（顺长轴滑行扫荡）**。

### 3.3 “较好定位效果”的五维多目标量化评估指标体系

在可行域 $\Omega_{\text{wing}}$ 内部，为科学衡量何为“较好的定位效果”，我们基于 AOA/DF 测向原理与 Cramér-Rao 下界，建立五大量化指标与实战机动代价函数：

1. **几何交会角 $\gamma(\rho; b, \alpha)$**：
   $$\sin\gamma = \frac{b\sin|\alpha|}{r_2(\rho)}, \quad \text{衡量双站测向线的正交解耦锐度。}$$
2. **定位多边形几何面积 $\mathcal{A}_{\text{loc}}(\rho; b, \alpha)$**：
   $$\mathcal{A}_{\text{loc}} = \frac{w_1(\rho) \cdot w_2(\rho)}{\sin\gamma} = \frac{4\rho r_2(\rho)\sin^2(1^\circ)}{\sin\gamma}, \quad \text{表征目标平面二维空间不确定度包络。}$$
3. **定位多边形外接长直径 $D(\rho; b, \alpha)$**：
   $$D \approx \frac{2\max(\rho, r_2)\sin(1^\circ)}{\sin\gamma}, \quad \text{用于判定是否可被 40m 光学圆一次性完全覆盖。}$$
4. **几何精度衰减因子 $\text{GDOP}(\rho; b, \alpha)$**：
   由测向 Fisher 信息矩阵 $J = \frac{1}{\sigma_\theta^2} H^T H$ 推导协方差矩阵迹，闭式导出无偏几何放大倍数：
   $$\text{GDOP}(\rho; b, \alpha) = \frac{\sqrt{\operatorname{tr}(J^{-1})}}{\sigma_\theta} = \frac{\sqrt{\rho^2 + r_2^2(\rho; b, \alpha)}}{\sin\gamma(\rho; b, \alpha)}$$
   定位平面均方根误差满足 $\text{RMSE}_{\text{pos}} = \sigma_\theta \cdot \text{GDOP}$。
5. **等效误差椭圆长短轴比 $\kappa(\rho; b, \alpha)$**：
   $$\kappa = \sqrt{\frac{\lambda_1}{\lambda_2}} \approx \cot\left(\frac{\gamma}{2}\right), \quad \text{量化目标不确定区域的各向异性畸变程度。}$$
6. **实战机动时间代价 $T_{\text{transit}}(b)$**：
   $$T_{\text{transit}}(b) = \frac{b}{v} = \frac{b}{5} \text{ 秒，距离每缩短 100m，直接节省 20 秒关键赛时。}$$

### 4.2 核心数学解算子：鲁棒射线交会与残差容错

对于同一频道在两点 $S_1(\mathbf{p}_1), S_2(\mathbf{p}_2)$ 测得的示向角 $\theta_1, \theta_2$，两单位方向向量为 $\mathbf{d}_1 = (\cos\theta_1, \sin\theta_1)^T, \mathbf{d}_2 = (\cos\theta_2, \sin\theta_2)^T$。
两射线参数方程：
$$\mathbf{x}(t_1) = \mathbf{p}_1 + t_1 \mathbf{d}_1, \quad \mathbf{x}(t_2) = \mathbf{p}_2 + t_2 \mathbf{d}_2, \quad (t_1 \ge 0, t_2 \ge 0)$$
联立解得两射线距离最近点或交点参数：
$$t_1 = \frac{(\mathbf{p}_2 - \mathbf{p}_1) \times \mathbf{d}_2}{\mathbf{d}_1 \times \mathbf{d}_2} = \frac{(x_2 - x_1)\sin\theta_2 - (y_2 - y_1)\cos\theta_2}{\sin(\theta_2 - \theta_1)}$$
估计目标坐标：
$$\mathbf{p}_{\text{est}} = \mathbf{p}_1 + t_1 \mathbf{d}_1$$

#### 容错机制设计：
若初次清除返回 `no_target_in_range`（极小概率落入示向误差边缘），机器狗以 $\mathbf{p}_{\text{est}}$ 为中心执行十字微步探测（偏移量 $\Delta = 15\text{ m} < R_{\text{clear}}$），实现 100% 容错闭环。

## 5. 问题四：含定向干扰源（带视野盲区）的主动搜索与清除策略

### 5.1 定向干扰源物理本质与信息缺失模型

* **物理特性**：定向源有效覆盖角度为定向角 $\phi_{\text{dir}}$ 两侧各 $90^\circ$（共 $180^\circ$ 扇区），背面 $180^\circ$ 为完全电磁静默区。
* **信息不确定性灾难**：
  $$\text{测向返回 } \texttt{"no_signal"} \iff \begin{cases}
  \text{原因 A：该频道不存在干扰源；} \\
  \text{原因 B：距离超过有效接收半径 } R_{\text{recv}} \in [1000, 1500]\text{ m}； \\
  \text{原因 C：机器狗正处在该定向源的 } 180^\circ \text{ 静默背面！}
  \end{cases}$$
* **结论**：单次 `no_signal` 绝对不能判定该频道无源。

### 5.2 贝叶斯占据栅格与多角度反投影感知算法

针对定向源盲区，建立**空间视线反投影与贝叶斯占据更新模型**。

#### 1. 多视角环绕观测定理（Surrounding Coverage Theorem）
**定理 5.1**：若机器狗围绕目标可能存在区域选择 $K \ge 3$ 个夹角互为 $120^\circ$ 的观测点进行全向环测，则对于任意朝向的定向干扰源（辐射角为 $180^\circ$），**必至少存在一个观测点严格落在其有效辐射扇区之内**。

* **证明**：反证法。设定向源辐射角区间为 $\Phi = [\phi_{\text{dir}} - \pi/2, \phi_{\text{dir}} + \pi/2]$，长度为 $\pi$。机器狗从三个环绕夹角为 $2\pi/3$ 的方向向目标观测。若三个方向均不落在 $\Phi$ 内，则三个方向必须全部落在长度仅为 $\pi$ 的静默半圆内。然而静默半圆的角跨度仅为 $180^\circ$，不可能同时包含两个互差 $120^\circ$ 以上的环绕向量。矛盾！故必至少有一点可接收到信号。证毕。

#### 2. 环形巡航网格参数设计
* 设立外围巡航圈半径 $R_{\text{patrol}} = 1150\text{ m}$，离散排布 8 个等分骨干航路点（方位角间隔 $45^\circ$）。
* 机器狗沿八边形骨干航路点巡航，在每一个航路点对未清除频道进行复查。此时即使原点位于定向源后方，当机器狗运行至目标侧向或正向航路点时，定向源信号必然被触发捕获！

## 6. 面向评测模拟器的工业级工程韧性与看门狗设计

为确保在进行实际测试时绝不发生异常闪退或 20 分钟硬超时，代码设计了三层防御盾：

```python
# 核心架构片段：幂等性重试与 18 分钟安全看门狗状态机
import json, time, math
from urllib.request import Request, urlopen

class SafeRobotCommander:
    def __init__(self, base_url="http://127.0.0.1:2026", robot_id="TEAM-2026"):
        self.base_url = base_url
        self.robot_id = robot_id
        self.req_counter = 0
        self.start_real_time = None
        self.max_real_s = 1200 # 20分钟
        
    def post(self, path, payload, max_retries=3):
        url = self.base_url + path
        data = json.dumps(payload).encode("utf-8")
        req = Request(url, data=data, headers={"Content-Type": "application/json"}, method="POST")
        
        for attempt in range(max_retries):
            # 看门狗机制：若真实运行时间超过 18 分钟 (1080s)，触发强制退出，保住有效日志
            if self.start_real_time and (time.time() - self.start_real_time > 1080):
                self.force_exit()
                return {"accepted": True, "exit_reason": "watchdog_timeout_protect"}
            try:
                with urlopen(req, timeout=3.0) as resp:
                    res = json.loads(resp.read().decode("utf-8"))
                    if res.get("accepted") is True:
                        return res
            except Exception as e:
                time.sleep(0.2) # 遇到网络抖动以原 request_id 幂等重试
        return {"accepted": False}
        
    def force_exit(self):
        exit_payload = {
            "arena_id": "default",
            "robot_id": self.robot_id,
            "request_id": f"exit-watchdog-{int(time.time())}"
        }
        self.post("/exit", exit_payload)
```
