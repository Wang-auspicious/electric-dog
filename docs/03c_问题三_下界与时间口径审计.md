Q3 理想时间口径审计（本地合成案例；不读取正式模拟器）

1. 若 N 个源的中心坐标 c_i 已知，清除点被强制取在中心，原点出发、终点自由的开放路径精确时间为 L_center*/5 + 5N；Held-Karp 可在 N<=16 求出。物理题允许清除点距中心 <=20m，所以该式是已知中心 oracle（可实现基准），不是严格物理下界。
2. 严格20m邻域下界：首边 w_0(i)=max(||c_i||-20,0)，源间 w(i,j)=max(||c_i-c_j||-40,0)。对所有排列求 min [w_0(pi1)+sum w(pij-1,pij)]，得到 L20*；任何实际清除路线都满足 T >= L20*/5+5N。把原点+源做同样权重的 MST 只给更松下界。固定800m二站、固定巡逻点、最近邻等均为启发式上界，禁止称严格下界。
3. 若额外假定 clear 前也要把频道切到该源，追加 n-1（频道1在源集）或 n 秒；q3_local_explore 的 clear 接口不计切频，因此主结果未追加。
4. 20个种子(N=10..16)结果：center oracle总时均1775.3s，中位1787.5s，按源均140.2s；20m严格LB总时均1677.3s，中位1691.3s，按源均132.6s。单源均匀圆域的直奔中心期望为 E[r]/5+5=(2*1800/3)/5+5=245s，可能解释网络评论中的“245”，但不是多源下界。评论中的180/220未注明单位和统计口径，不能作为理论下界。
